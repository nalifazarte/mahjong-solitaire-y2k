# Mahjong Solitaire Y2K\n\nPWA offline de Mahjong Solitaire.\n\n- Sem anúncios.\n- Funciona offline depois do primeiro carregamento.\n- Layouts Mini (32), Medium (72) e Classic (144).\n- Tabuleiro gerado com solução determinística por backtracking.\n- A solução de cada layout fica somente em memória durante a sessão.\n- Nova partida reutiliza o solver em cache.\n\n## GitHub Pages\n\nEm Settings → Pages, selecione Deploy from a branch, branch main e folder /(root).\n\nURL esperada: https://nalifazarte.github.io/mahjong-solitaire-y2k/\n
